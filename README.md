## Why this isn't a Vite/React/Tailwind app

This sandbox environment had **no network access** to npm, any CDN, or apt â€”
every package registry was blocked at the network level. So instead of a
framework that couldn't be installed, this is a **dependency-free static
site**: plain HTML/CSS/JS, generated by a small custom Node build script
(`build.js`) so components (header, footer, cards, tables, sidebar, etc.)
are still written once and reused everywhere, not copy-pasted per page.

There are zero runtime dependencies. Everything here â€” including the
build tool itself â€” is plain Node.js `fs`/`path`, so it will run anywhere
Node runs, with no `npm install` required. This also means it is
straightforward to port into React/Vite/Next later: the component
functions in `src/components/*.js` already return the exact markup each
piece needs; converting a function like `featureCard()` into a React
component is close to a 1:1 translation.

## Run it

```
node build.js      # builds the static site into ./dist
node serve.js       # serves ./dist at http://localhost:4173
```

Then open http://localhost:4173/index.html.

No `npm install` is required â€” there are no dependencies.
